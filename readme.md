# Sistema de Gestão de Estoque

## Introdução
O Sistema de Gestão de Estoque é uma aplicação web desenvolvida para auxiliar empresas no controle de produtos, entradas, saídas e quantidades disponíveis em estoque.

## Objetivo
Desenvolver uma ferramenta para organizar o estoque, acompanhar movimentações e identificar produtos que precisam de reposição.

## Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
- LocalStorage

## Funcionalidades
- Cadastro de produtos.
- Identificação por código.
- Organização por categorias.
- Controle de preços e quantidades.
- Registro de entradas e saídas.
- Alerta de estoque baixo.
- Pesquisa de produtos.
- Histórico de movimentações.
- Exclusão de produtos.
- Armazenamento de dados no navegador.

## Regras de negócio
- Não permite códigos de produtos duplicados.
- Não permite quantidades negativas.
- Impede saídas maiores que o estoque disponível.
- Considera estoque baixo quando há cinco unidades ou menos.

## Como executar
1. Baixe ou clone o repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo index.html em um navegador.
